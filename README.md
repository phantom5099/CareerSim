# CareerSim · 求职模拟器

> 还在为秋招一无所获苦恼吗？还在为春招形势不好担忧吗？那就快来使用 CareerSim 吧！主打一个简历投到爽，面试面到爽，Offer 拿到手软！

你可以体验到：

### 简历投到爽

不必苦恼找不到合适的公司、合适的岗位投递了，打开 CareerSim，你永远有的投。今天投大厂，明天投创业公司，后天换个小而美的团队；技术、产品、运营、设计，想投什么投什么。简历改一版就投一版，看看哪句话能把已读不回变成面试邀约。

### 面试面到爽

不必担心约不到面试、聊两轮就没下文了，打开 CareerSim，你永远有的面。技术面、业务面、HR 面，一面、二面、交叉面，想面几轮面几轮。面试官会追着你的项目问，答不上来就换个角度再答；这场凉了，下一场马上开。

### Offer 拿到手软

不必羡慕别人手里一把 Offer、自己却两手空空，打开 CareerSim，你也能拿到手软。月薪、奖金、期权、试用期，一项项谈；想硬气就多要一点，想稳一点就见好就收。谈崩了可以重来，谈成了还能拒一个试试——反正这里的 Offer 管够，只要你会谈。

## 分数不是拍脑袋

简历看五件事：岗位匹配、项目深度、成果量化、结构表达、稳定性。每个维度按行为锚定打 1–5 分，再换算成百分制。报告不只给分，还会引用你的原句，告诉你哪句加分、哪句拖后腿，以及怎么改。

面试也一样：专业能力、项目深度、问题解决、沟通结构、动机匹配，一项项打分，配原话证据和 STAR 四格。你能看到自己缺的是情境、任务、行动还是结果。

当然，你还要面临以下不可避免的问题：

- 你觉得自己挺合适，岗位却只招一个人。能力够了只是拿到入场券，最后录不录，还得看名额和同场竞争的人。
- 有时候输的不是回答，是流程。邀约忘了确认、笔试没答完、面试当天没起来，这些都会让你出局，但它们不算进能力分。
- 还有些事纯看运气：HC 说冻就冻，面试官临时改期，聊到一半发现候选人里有个自带三年大厂经验的。碰上了就碰上了，复盘里会单独标出来，不往你头上扣。

## 这里没有真实的后果，但有真实的规则

公司是虚构的，岗位是虚构的，面试官也是模拟的。但你收到的拒信会告诉你卡在哪一轮、为什么卡、下次怎么改；你拿到的 Offer 会把薪资结构写清楚；你谈崩的每一次，都能在复盘里看到是哪句话把天聊死了。

## 最后

求职这件事，运气占一部分，流程不熟占一部分，剩下才是能力。CareerSim 想帮你把前两部分先练掉。
